# CTS text runtime API v1

Independent local Python API: `from cts_text import TextEngine`. Install the existing Argos models before use. `TextEngine("en","pt",profile="cuda",allow_cpu_fallback=True).translate(text)` supports direct, installed model pairs only. Profiles: serial, cpu (CTranslate2 batching), cuda (CTranslate2 batching). GPU startup performs a real warmup and may fall back to CPU only before translation begins. Runtime errors are explicit. `identity` records the effective backend, model and runtime version; use it in durable checkpoint keys. `fallback_reason` is a class name, never private text. No network, voice, API server or cloud dependency. On Windows optional `CTS_CUDA_DLL_DIRS` points at locally installed NVIDIA DLL directories; do not put arbitrary downloaded libraries on PATH. The guarded batch implementation requires Argos 1.11.0. Translation quality is experimental. No claim of contextual LLM or glossary preservation. Human QA is required before selecting a default.
